# Rafiz Portfolio - Moshfiq Ahmed Rafi

A modern, high-performance personal portfolio website built with **Next.js 15**, **React 19**, and custom CSS.

## 🚀 Overview

- **Name**: Moshfiq Ahmed Rafi (Rafiz)
- **Role**: Software Engineer & AI / Machine Learning Researcher
- **Education**: B.Sc. in Software Engineering, Daffodil International University

## ✨ Features

- **Modern Glassmorphic Dark UI**: Premium design with glowing accents and sleek typography.
- **Dynamic Interactive Sections**:
  - Hero with status badges, quick stats, and direct CTA buttons
  - About & Academic background (Daffodil International University, IIT Bombay, SPbU)
  - Interactive Filterable Projects Showcase
  - Events & International Milestones Gallery
  - Technical Skills matrix & Core Competencies
  - Leadership, Volunteering & Extracurricular Activities
  - Interactive Contact Form & direct social channels
- **Fast & Responsive**: Mobile-friendly layout with optimized static pre-rendering.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Vanilla CSS with modern custom design system

## 📦 Getting Started

### Prerequisites

- Node.js (v18.17 or later recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone <repo-url>
   cd "rafiz portfolio"
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the portfolio.

### Building for Production

```bash
npm run build
npm run start
```
